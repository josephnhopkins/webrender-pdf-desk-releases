# Webrender Pdf Desk — releases

Downloads for **Webrender Pdf Desk**, a small desktop program for reading and marking up PDF
files, from Nextwaveweb Ltd — for Windows and macOS. What it is, the download links and what to
expect on first run are on its page:

**https://nextwaveweb.co.uk/products/webrender-pdf-desk**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the downloads as its assets. Every download carries a README (what you need,
setting up, the first-run warning, saving, removal) and a `THIRD-PARTY-NOTICES.txt` listing the
open-source components it is built from — `README.txt` beside the program in each zip.

Windows and macOS are at 0.1.0. A Linux build follows.
